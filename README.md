# GATE ARMY

スマホ縦持ちとPCマウスに対応した、Three.js製の部隊増強ランナー。

## 起動

Node.jsがある環境で、このフォルダから `node serve.mjs` を実行し、
http://127.0.0.1:4173 を開きます。Windowsでは `play.cmd` でも起動できます。
`index.html` の直接ダブルクリックではなく、HTTPサーバー経由で開いてください。
GitHub Pagesなどの静的ホスティングにもそのまま配置できます。
Three.js 0.180.0はvendorに同梱。ゲーム実行時のCDNアクセスはありません。

## 操作とルール

- PC：画面内でマウスを左右に動かす。左右キー / A・Dも対応。
- スマホ：触れた位置から左右ドラッグ。触れた瞬間には飛びません。
- 数字ゲートは編成ポイントを増減。＋と−は現在の兵種の増減体数（戦車は両数）を表示し、兵種コストの整数倍で増減します。除算は1/3などの分数表記。＋20%・−30%は編成ポイントを割合で増減。倍率は×1.2などの小数表記です。看板は演算だけを大きく表示します。
- 兵種ゲートは歩兵・対戦車砲兵・戦車の3択。次の敵を上部に表示。
- 編成コストは1・3・10。ポイントの余りは保存されます。
- 相性は歩兵→砲兵→戦車→歩兵。同予算で優位ですが、物量で逆転できます。
- 戦闘は停止して自動射撃。撃破された兵種のコスト分のポイントを失います。
- 4戦突破でクリア。次のセクターは敵の予算が増え、基本40ポイントに持ち越しボーナスを加えて出撃。
- 一時停止ボタン / Escapeで停止。タブを離れた際も自動停止。
- 音は初期ON。出撃ボタンで音声を開始します。右下でON/OFF切替、設定を保存します。
- オリジナルのシンセBGM（ベース・パッド・アルペジオ・ドラム）と、兵種別発射音・爆発・編成変更・増減・勝敗音。交戦中はBGMが厚くなります。
- 一時停止・タブ移動で音楽も停止。サウンドはWeb Audioで合成し、外部音源は使用しません。

大軍では描画体数を制限し、実数はHUDで表示します。兵種の攻撃力・耐久は
core.mjsに集約。戦闘は同時ダメージの固定時間刻みで処理します。
形状はオリジナルの手続き生成。画像素材のダウンロードは使用していません。

## 検証

`node tests/core.mjs`：編成の余り、数字演算、同予算での相性、物量の逆転を検証。

`node tests/browser.mjs`：PlaywrightとChromeが必要です。ローカルサーバーを
PORT=4174で起動した上で実行。PLAYWRIGHT_PATHでPlaywrightの場所を指定できます。
PC/スマホ操作、クリア、次セクター、敗北、一時停止を検証します。
スクリーンショットはtests/artifactsに生成します（Git管理対象外）。

Three.jsのライセンスはvendor/LICENSE。

`node tests/sound.mjs`：兵種換算表示、BGMの音声信号、発射音・爆発音、一時停止・ミュート・設定保存を検証します。ブラウザテストと同じ環境が必要です。

`node tests/gates.mjs`：スマホ寸法で分数・割合・小数倍率・兵種の全看板を撮影し、出現とクリアを確認します。

## 戦闘バランス

同予算の有利側は、大部隊では約半分の戦力を残して勝つよう調整。
損傷したユニットは残り耐久に応じて火力が低下します。
射撃効率は0.25秒ごとに両軍独立で±10%変動。見た目のフレームレートには連動しません。
乱数はダメージにだけ作用し、コスト・ゲート演算・編成の余りには作用しません。

`node tests/balance.mjs`：各相性・10〜1000ポイント・各300乱数シードで勝率と残存率を検証。
同兵種の公平性、接戦の揺らぎ、物量逆転、60/120Hzの比較、ステージ1の最適ルートも確認。

## ランダムゲート

各出撃で数字・演算・左右配置を生成し直します。現在の兵種コストに合わせ、
定数の加減算と倍率・割合の損益分岐が現在の人数付近になるよう生成。
表示中の看板は固定され、近づいている途中に再抽選しません。
序盤は増強、途中に損失ゲートを入れる構成は維持し、数値と組み合わせを変えます。

`node tests/generation.mjs`：多様性、正解側の偏り、人数での正解反転、表示とコストを検証。
?debug=1では`__army.start(数値seed)`でゲート生成を再現できます。

## ジオラマ描画

道路脇に前庭と駐車車両のある家、屋上設備付きの低層ビル、畝と作物のある畑、駐車場、トーチカ・土のう・木箱を配置。
歩道・縁石・側溝・街灯・横断歩道・柵を街区ごとにつなぎ、道路と草地も街並みと同じ方向・速度でスクロールします。
街区の形状をまとめて描画し、オブジェクトを増やしても描画回数を抑えています。
部隊は塗装模型を意識した造形で、装備・砲架・履帯・砲塔を描画します。
部隊全体の幅で進路を制限し、端に寄せた際の重なりを防ぎます。
同じ兵種の形状をインスタンス描画し、歩兵120・砲兵18・戦車15までを代表表示。
射撃の閃光・砲身反動、火球・煙・土煙・衝撃波・破片・短時間の残骸を追加。血しぶきは使用しません。
形状・路面・草地・煙テクスチャはコードで生成し、外部画像素材は使用しません。

`node tests/presentation.mjs`：PC/スマホ寸法で造形を撮影。隊形、演出停止、再出撃、描画回数と共有形状のリソース解放を検証。

`node tests/town.mjs`：町のオブジェクト、道路・草地・街区のスクロール方向と速度、一時停止・再出撃を検証。

## 兵站と持ち越し

兵站Bは初期0.30、範囲0.05〜0.95。次ステージは40＋floor(B×min(残存ポイント,100))で開始します。
各数字看板に独立11%でアイテムが付きます。補給はB＋0.10、毒は走行1mにつきB−0.0006。毒は重複せず、戦闘・一時停止中は減らず、次ステージで解除します。
良いアイテムは控えめな数字、悪いアイテムは豪華な数字になる傾向が80%、逆の組み合わせが20%あります。
コンティニューはステージ開始時のB・ボーナスを復元。看板は再抽選します。NEW GAMEはステージ1・40ポイント・B0.30へ戻ります。
敵の予算は従来どおりステージごとに基準の18%ずつ増加します。

`node tests/logistics.mjs`：持ち越し・兵站上下限・毒・アイテム頻度を検証。
`node tests/logistics-browser.mjs`：PC/スマホの持ち越し、コンティニュー、NEW GAMEと表示を検証。
